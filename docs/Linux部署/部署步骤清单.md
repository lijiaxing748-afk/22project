# Ubuntu 部署步骤清单（实验室机器执行）

> 本文是**部署过程的操作单**，按顺序执行即可。
> 每一步都有验证方法，通过后再进下一步。

---

## 前置检查

```bash
# 网络（iPhone USB 共享）
ping -c 3 www.baidu.com

# 项目目录
ls ~/work/
# 应看到：backend  frontend  docs  README-部署包说明.txt
```

---

## 步骤 1 · 安装系统依赖

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip mysql-server
```

**验证**：

```bash
systemctl status mysql --no-pager | head -5
mysql --version
python3 --version
```

**期望**：`Active: active (running)`、MySQL 8.0.x、Python 3.12.x

---

## 步骤 2 · 配置 MySQL 密码

Ubuntu 上 MySQL 的 root 默认走 `auth_socket`（免密）。后端需要密码登录，所以要设一个：

```bash
sudo mysql -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'Model@2026'; FLUSH PRIVILEGES;"
```

**验证**（用密码能登进去）：

```bash
mysql -u root -p'Model@2026' -e "SELECT VERSION();"
```

> ⚠️ 记住这个密码，下一步要写进 `db.env`。

---

## 步骤 3 · 创建配置文件 db.env

```bash
cd ~/work/backend
cp db.env.example db.env

# 生成一个固定的签名密钥
python3 -c "import secrets; print(secrets.token_hex(32))"
# 把输出复制下来，下一步要用
```

**编辑配置**：

```bash
nano db.env
```

**需要改的两项**：

```bash
MODEL_DB_PASSWORD=Model@2026
MODEL_SECRET_KEY=<上一步生成的 64 位串>
```

**保存**：`Ctrl+O` → `Enter` → `Ctrl+X`

**验证**：

```bash
grep -E "^MODEL_DB_PASSWORD|^MODEL_SECRET_KEY" db.env
# 两项都不应为空
```

---

## 步骤 4 · 初始化数据库

```bash
cd ~/work
bash docs/Linux部署/init-database.sh
```

**脚本会**：
1. 读 `db.env` 的连接信息
2. 执行 `schema_mysql.sql`（建表）
3. 执行 `auth-migration.sql`（建鉴权表）
4. 校验所有表是否创建成功

**验证**：

```bash
mysql -u root -p'Model@2026' model_management -e "SHOW TABLES;"
```

**期望看到 11 张表**：
```
Datasets, EdgeDevices, InferenceResults, InferenceTasks,
ModelDeployments, ModelInvocations, Models, OperationLogs,
Roles, Trainings, Users
```

---

## 步骤 5 · 安装 Python 依赖（最慢）

```bash
cd ~/work/backend
bash ../docs/Linux部署/install-backend.sh
```

**脚本会**：
1. 检测 Python 版本（需 3.10+）
2. 创建 `venv` 虚拟环境
3. 从 PyTorch CPU 源安装 `torch==2.14.0+cpu`
4. 安装 `requirements.txt` 其余依赖

**⚠️ 这步耗时 20-40 分钟**，要下载 TensorFlow / PyTorch（1GB+）。
**⚠️ 走 iPhone 流量的话注意流量消耗。**

**验证**：

```bash
cd ~/work/backend
./venv/bin/python -c "
import flask, waitress, pymysql, tensorflow, torch
print('flask    :', flask.__version__)
print('tensorflow:', tensorflow.__version__)
print('torch    :', torch.__version__)
print('全部导入成功')
"
```

## 步骤 6 · 手工试跑（先别注册服务）

```bash
cd ~/work/backend
./venv/bin/python serve.py
```

**终端应打印**：

```
监听地址   : 0.0.0.0:8080
数据库     : 127.0.0.1:3306/model_management
令牌密钥   : 已固定          ← ★ 必须是"已固定"
```

**另开一个终端验证**：

```bash
curl -s http://127.0.0.1:8080/health | python3 -m json.tool
```

**重点看**：

| 字段 | 期望值 |
| --- | --- |
| `service` | `ok` |
| `database.ok` | `true` |
| `auth.key_is_default` | **`false`**（密钥已固定） |
| `artifacts.count` | 3 |

**浏览器测试**：打开 `http://127.0.0.1:8080`，用 `admin` / `Admin@2026` 登录。

**⚠️ 确认没问题后，`Ctrl+C` 停掉**，再往下走。

---

## 步骤 7 · 注册 systemd 服务

```bash
cd ~/work
sudo bash docs/Linux部署/install-service.sh
```

**脚本会**：
1. 填充 `model-platform.service` 模板中的占位符
2. 写到 `/etc/systemd/system/`
3. `systemctl enable`（开机自启）
4. `systemctl start`（立即启动）
5. 探测 `/health` 验证
6. 配置 `ufw` 防火墙（如果启用了）

**验证**：

```bash
sudo systemctl status model-platform --no-pager | head -10
systemctl is-enabled model-platform
curl -s http://127.0.0.1:8080/health | python3 -m json.tool | head -5
```

**期望**：`active (running)`、`enabled`、`"service": "ok"`

---

## 步骤 8 · 局域网访问验证

```bash
# 查本机 IP
ip addr show | grep "inet " | grep -v 127.0.0.1

# 确认监听所有网卡
sudo ss -ltnp | grep 8080

# 确认防火墙
sudo ufw status
```

**在另一台机器上**（或用手机连同一个 WiFi）浏览器打开：

```
http://<服务器IP>:8080
```

能打开登录页即成功。

## 步骤 9 · 交付前自查

| 检查项 | 命令 | 预期 |
| --- | --- | --- |
| 服务运行中 | `sudo systemctl status model-platform` | `active (running)` |
| 开机自启 | `systemctl is-enabled model-platform` | `enabled` |
| MySQL 运行中 | `systemctl is-active mysql` | `active` |
| 健康检查 | `curl -s http://127.0.0.1:8080/health` | `"service": "ok"` |
| 数据库连通 | 同上 | `database.ok: true` |
| 密钥已固定 | 同上 | `key_is_default: false` |
| 前端产物存在 | `ls ~/work/frontend/dist/index.html` | 存在 |
| 监听地址 | `sudo ss -ltnp \| grep 8080` | `0.0.0.0:8080` |
| 防火墙放行 | `sudo ufw status` | `8080/tcp ALLOW` |
| 三个账号可登录 | 浏览器依次登录三个账号 | 都能登录 |

## 步骤 10 · 备份配置（交付前）

```bash
mkdir -p ~/backup

# 数据库
mysqldump -u root -p'Model@2026' model_management > ~/backup/db-initial.sql

# 配置
cp ~/work/backend/db.env ~/backup/db.env.bak

# 记录环境信息
{
  echo "=== 部署时间 ==="
  date
  echo "=== 系统版本 ==="
  lsb_release -a
  echo "=== 本机 IP ==="
  ip addr show | grep "inet " | grep -v 127.0.0.1
  echo "=== 服务状态 ==="
  systemctl is-active model-platform
} > ~/backup/deploy-info.txt
```

## 遇到问题时的排查顺序

```bash
# 1. 服务状态
sudo systemctl status model-platform

# 2. 最近日志（最关键）
sudo journalctl -u model-platform -n 100 --no-pager

# 3. 健康检查
curl -s http://127.0.0.1:8080/health | python3 -m json.tool

# 4. 端口
sudo ss -ltnp | grep 8080

# 5. 数据库
mysql -u root -p'Model@2026' model_management -e "SHOW TABLES;"
```

详细排查见《模型管理平台 · 系统使用文档（Ubuntu 版）》第 6 章。
