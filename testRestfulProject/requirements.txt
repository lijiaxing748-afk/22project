#  安装（联网）：
#      venv\Scripts\python.exe -m pip install -r requirements.txt
#
#  安装（离线，用打包好的 wheel）：
#      venv\Scripts\python.exe -m pip install --no-index ^
#          --find-links="...\02-Python离线依赖" -r requirements-offline.txt
#    注意离线请用 offline_package 里的 requirements-offline.txt，
#    它按本文件 + 本机真实环境生成，并包含下面的 torch 处理方式。
#
#  ---------------------------------------------------------------
#  两个容易踩的坑（2026-09-16 修正）：
#
#  1) 本文件原先**漏了 tensorflow**，而 1DCNN 全靠它。
#     照旧版装完会报 `No module named 'tensorflow'`。
#     现补上 tensorflow==2.21.0。
#
#  2) tensorflow / keras 的版本口径 —— ✅ 2026-09-28 已统一到正式版（本文件现在**就是**真实环境）：
#     本文件钉 **tensorflow==2.21.0 + keras==3.15.1**（正式版，也是离线包与 Linux 部署用的口径）。
#
#     历史（留档，免得以后又踩）：2026-09-27 之前，本机 venv 是 **Python 3.14 + nightly**
#     （tf_nightly 2.22.0.dev + keras_nightly 3.16.0.dev），与这里的钉版**不一致**：
#     · Python 3.14 上 PyPI 只有 tensorflow 2.22.0rc0，**根本装不上 2.21.0**（实测 No matching distribution）；
#     · data/models/1dcnn/model.keras 又是由 Keras 3.16.0.dev 存出来的，能否被正式版加载**没人验证过**。
#     2026-09-28 的处理：把开发环境**降到 Python 3.12.5 + 正式版**（用 py -3.12 建新 venv 重装本文件），
#     并**实测**了那份既有存档：`keras.saving.load_model(model.keras)` 在 keras 3.15.1 / TF 2.21.0 下
#     **能正常加载**（cnn，输入 (None,784,1)、输出 (None,10)、102018 参数）→ 兼容性风险关闭，
#     因此**不需要**重新训练 1DCNN。（原 venv 备份在 testRestfulProject/venv-py314-backup-*，确认无误后可删。）
#
#     ⚠️ 换机器/换 Python 版本时请照本文件装（含上面的 PyTorch CPU 索引那一行）；
#        判断"真实环境是什么"以 `pip freeze` 为准（tools/check-requirements.py 就是拿本文件与它对拍的工具）。
#
#  ---------------------------------------------------------------
#  torch 的安装方式：
#
#     `torch==2.14.0+cpu` 里的 `+cpu` 是 **local version 标记**：这种轮子
#     **不在 PyPI 上**，只在 PyTorch 官方 CPU 索引里。如果只写一个 `torch==2.14.0+cpu`，
#     默认走 PyPI 会直接失败（实测报错：No matching distribution found，且列出的可用版本
#     里只有 2.9.0 … 2.14.0，没有 +cpu）：
#
#         ERROR: No matching distribution found for torch==2.14.0+cpu
#
#     ✅ 本文件已用下面这行把 PyTorch 的 CPU 索引加进来（pip 支持 requirements 里的选项行），
#        所以现在**直接 `pip install -r requirements.txt` 就能装上**，不必再手工分两步：
#
#  ↓↓↓ 就是这一行（别删）↓↓↓
--extra-index-url https://download.pytorch.org/whl/cpu
#
#     ⚠️ 离线/内网：改成把 wheel 都下好再装 —— 记得 `torch-2.14.0+cpu-*.whl` 也要在 wheel 目录里
#        （从 https://download.pytorch.org/whl/cpu 下），然后：
#            pip install --no-index --find-links=<wheel目录> -r requirements.txt
#        （`--no-index` 会让上面那行 extra-index 自动失效，不需要改本文件）
#     ⚠️ 若换成别的 torch 版本，务必同时改这里的 `+cpu` 钉版与上面的索引说明；
#        用默认的 CUDA 版会到 2.5 GB 以上，而本平台**用不到 GPU**（CPU 版约 118 MB）。
#
#  ---------------------------------------------------------------
#  adtk 说明：
#
#     adtk 是**源码内置**在项目里的（testRestfulProject/adtk/），
#     不从 PyPI 装，所以不列在这里。
#     但它依赖 statsmodels / tabulate —— 这两个已在下方清单中，
#     且依赖它们的 formulaic / patsy / interface-meta 也一并列出。

# cryptography：**MySQL 8 认证插件必需**。
#   Linux 上 MySQL 8 的默认认证插件是 caching_sha2_password，PyMySQL 连接它时
#   **强制要求**本包，否则抛：
#       RuntimeError: 'cryptography' package is required for sha256_password
#       or caching_sha2_password auth methods
#   ⚠️ PyMySQL 自身**不携带**该依赖（其 Requires 为空），必须显式声明。
#   该报错信息隐晦，容易被误判为"密码错误"或"网络不通"，故在此明示。
#   Windows 上装了也无害（本机 MySQL 用旧插件时用不到而已）。
