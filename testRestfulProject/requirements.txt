# =====================================================================
#  模型管理平台 · 后端 Python 依赖
#
#  安装（联网）：
#      venv\Scripts\python.exe -m pip install -r requirements.txt
#
#  安装（离线，用打包好的 wheel）：
#      venv\Scripts\python.exe -m pip install --no-index ^
#          --find-links="...\02-Python离线依赖" -r requirements-offline.txt
#    注意离线请用 offline_package 里的 requirements-offline.txt，
#    它按本文件 + 本机真实环境生成，并包含下面的 torch 处理方式。
#
#  ---------------------------------------------------------------
#  两个容易踩的坑（2026-09-16 修正）：
#
#  1) 本文件原先**漏了 tensorflow**，而 1DCNN 全靠它。
#     照旧版装完会报 `No module named 'tensorflow'`。
#     现补上 tensorflow==2.21.0。
#
#  2) 原先写的是 keras-nightly==3.16.0.dev2026091204（开发版），
#     但实际在用的是正式版 keras 3.15.1，与 TF 2.21 配套。
#     装 nightly 会版本不匹配，现改为 keras==3.15.1。
#
#  ---------------------------------------------------------------
#  torch 的正确安装方式：
#
#     `torch==2.14.0+cpu` 这种带 +cpu 后缀的包**不在 PyPI 上**，
#     只在 PyTorch 官方 CPU 索引里。直接 pip install 本文件会失败：
#
#         ERROR: No matching distribution found for torch==2.14.0+cpu
#
#     正确做法是先单独装 torch：
#
#         venv\Scripts\python.exe -m pip install torch==2.14.0+cpu ^
#             --index-url https://download.pytorch.org/whl/cpu
#
#     再装其余依赖。或者像离线包那样，预先 `pip download` 把 wheel 存下来。
#     （CPU 版约 118 MB；若装默认的 CUDA 版会到 2.5 GB 以上，本平台用不到 GPU。）
#
#  ---------------------------------------------------------------
#  adtk 说明：
#
#     adtk 是**源码内置**在项目里的（testRestfulProject/adtk/），
#     不从 PyPI 装，所以不列在这里。
#     但它依赖 statsmodels / tabulate —— 这两个已在下方清单中，
#     且依赖它们的 formulaic / patsy / interface-meta 也一并列出。
# =====================================================================
